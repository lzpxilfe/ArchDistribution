# ArchDistribution 사용 안내

[README로 돌아가기](../README.md) · [변경 기록](../CHANGELOG.md)

## 자료를 준비할 때

- 조사구역 폴리곤과 주변유적 벡터 레이어를 QGIS에 불러옵니다. 수치지형도와 배경 음영기복도는 선택입니다.
- 레이어의 CRS가 원자료와 일치하는지 확인합니다. 분석에 적합한 미터 투영좌표계는 그대로 사용하며, 경위도나 웹 메르카토르 자료는 조사구역을 기준으로 지역 UTM을 선택합니다. 버퍼·거리·면적은 분석 좌표계에서 평면으로 계산합니다.
- SHP의 한글이 깨지면 **세부 설정**의 자료 역할 표에서 해당 레이어의 인코딩을 직접 고릅니다. 자동 감지는 인코딩 선언과 DBF 앞부분의 표본을 사용합니다.

## 중복 검토와 번호

기록마다 **원자료의 유적·조사**, **기록 사이의 관계**, **도면에서 보이는 번호**를 구분합니다. 예를 들어 하나의 유적에 대한 분포지도 기록과 발굴조사 기록을 연결하면서 각각의 조사 정보를 보존할 수 있습니다.

| 처리 | 지도에서의 의미 |
| --- | --- |
| **별도 유지** | 서로 다른 기록에 번호를 각각 부여합니다. |
| **연결만** | 관계를 남기고 번호는 각각 유지합니다. |
| **대표 번호로 묶기** | 같은 번호를 쓰며 원자료와 검토 근거를 남깁니다. |

- **세부 설정 → 자료 역할 및 중복 판정**에서 역할 자동 인식을 확인하고 필요하면 직접 수정합니다. 지정유산의 구성 요소를 상위 유적과 같은 번호로 실을지도 여기서 고릅니다.
- **기존 결과 후속 작업 → 번호만 다시 매기기**는 현재 도곽과 정렬 설정으로 대표 결과의 번호를 바꿉니다. 중복 결정을 바꾸려면 원자료를 선택해 분석을 다시 실행합니다.
- 검수표와 중복 보존 레이어는 결과 그룹에서 확인합니다. 원본 입력 레이어는 프로젝트의 **ArchDistribution_원본_데이터** 그룹으로 모입니다.
- 속성 분류에서 시대·성격·제외 규칙을 확인할 수 있습니다. 제외된 기록과 이유는 **제외_기록**에서 확인합니다.

판정 관계의 정의와 대표 선택 규칙은 [판정 규칙 문서](research/ontology-and-decision-rules.md)에 있습니다.

## 지정·보호구역과 매장유산 유존지역

- 지정유산·보호구역과 현상변경 기준을 분포지도에 담으려면 **세부 설정**에서 해당 법정 레이어와 필드를 선택합니다.
- **매장유산 유존지역** 탭은 보존조치별 형상을 출력하는 별도 흐름입니다. 유존지역과 기준 조사구역을 선택하고 보존조치 필드를 확인합니다. 조치가 여러 개인 유적은 형상별 심볼과 유적 번호를 함께 표현할 수 있습니다.
- 도곽 가장자리의 미세 조각 제외는 도곽에서 실제로 잘린 폴리곤에 적용됩니다. 도곽 안에 온전히 들어온 작은 유적은 유지합니다.

## 파일 저장과 인쇄

| 선택 | 저장 결과 |
| --- | --- |
| GeoPackage + 실행정보(JSON) | 결과 레이어와 검수표, 입력·출력 요약과 실행 설정 |
| JPG / PDF | 선택한 용지와 축척의 지도. QGIS 조판 관리자에서 편집 가능한 조판도 확인 가능 |
| 주변유적 현황표(HWPX·CSV) | 번호, 유적명, 시대, 성격, 소재지, 이격거리, 출전, 비고 |

- 같은 주소가 여러 기록에 반복되면 필지를 중복 계산하지 않습니다. 중복 범위를 확인할 수 없으면 표에 확인 가능한 최소 필지 수를 `이상`으로 표시합니다.
- 번호와 원자료를 대조한 뒤 제출하세요. 연구나 업무 기록을 보관할 때는 실행정보 JSON과 원자료의 제공처·버전을 함께 남깁니다.
- 조판을 직접 만들 때에는 지도 항목의 CRS를 `도곽_Extent`와 맞춥니다. PDF를 편집할 계획이라면 지형도·유적·버퍼를 각각 표시하여 내보낼 수 있습니다.

## 문제 해결

| 증상 | 확인할 곳 |
| --- | --- |
| 설치 ZIP을 인식하지 못함 | ZIP 루트 아래 `ArchDistribution/metadata.txt`가 있는지 확인 |
| 지도가 비어 보임 | 결과 그룹과 레이어의 가시성 확인, 결과 레이어 우클릭 후 **레이어로 확대** |
| 거리가 예상과 다름 | 원자료의 CRS와 실행정보에 기록된 분석 CRS 확인 |
| 실행에 실패함 | QGIS 프로필의 `ArchDistribution/latest_log.txt`에서 오류 메시지 확인 |

공개 이슈에 실제 유적의 민감 좌표나 비공개 원자료를 붙이는 대신, QGIS·플러그인 버전과 가상 자료로 재현하는 절차를 적어 주세요.
