# ArchDistribution 빠른 시작 예제

1. 두 파일을 QGIS에 불러옵니다. `quick-start.gpkg`에서는 **가상 조사구역**과 **가상 유적분포지도**를 모두 추가합니다.
2. `quick-start-hillshade.tif`를 레이어 목록 맨 아래에 놓습니다. 가상 조사구역을 우클릭해 **레이어로 확대**할 수 있습니다.
3. ArchDistribution을 열고 조사구역과 주변유적을 선택합니다. 도곽 축척은 **1:25,000**, 스타일·분석의 버퍼는 **500 m**입니다.
4. **분포지도 만들기**를 누른 뒤 레이어 패널에서 결과 그룹과 유적 번호를 확인합니다.

조사구역과 유적은 모두 가상입니다. GeoTIFF는 실제 지형의 배경 이미지로, Hillshade Korea의 음영 계산을 Copernicus DEM GLO-30에 적용했습니다.
